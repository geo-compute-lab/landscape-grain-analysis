# Suggested supplementary-code description (for manuscript/submission portal)

**Supplementary Code S1.** Analytical scripts and workflow templates for the multi-scale landscape grain-size analysis applied in the Haikou study. The package includes scripts for landscape metrics analysis, information-retention assessment, trend and change-point analysis, and an ArcGIS 10.2 rasterization workflow template. The original Haikou survey data, water-vector data, and per-grain-size landscape metric sequences are not included because they are not publicly available.

## Proposed Data availability text

The land-use survey data and water-vector data used in this study are not publicly available due to data access restrictions. The analytical scripts and workflow templates used for the study are provided as Supplementary Code S1. The original input data and per-grain-size landscape metric sequences are not included; therefore, the exact Haikou results cannot be reproduced from the code package alone.
