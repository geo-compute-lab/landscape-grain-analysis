# Suggested supplementary-code description (for manuscript/submission portal)

**Supplementary Code S1.** Documented analytical scripts and workflow templates for implementing the multi-scale landscape grain-size determination procedure. The package covers GIS rasterization rules (ArcGIS 10.2 template and pseudocode), landscape class area error Ei, regional landscape change index V, operational information-retention screening, reference-corridor continuity checking, sequential Mann–Kendall diagnostics, original and Hamed–Rao modified Mann–Kendall tests, Pettitt change-point analysis, and core-metric breakpoint integration. No example datasets, restricted land-use survey data, continuous water vectors, actual per-grain-size metric sequences, or real coordinates are included. Users must prepare their own input data according to the accompanying documentation. The code must be verified by the authors in the study's computational environment before claiming that it reproduces the reported empirical results.

## Proposed Data availability text (use only after verifying and uploading the code)

The land-use survey data and continuous water-vector data used in this study are subject to data-access and confidentiality restrictions and therefore cannot be publicly shared. The per-grain-size landscape metric sequences derived from these datasets are not publicly available under the current data-release constraints. The aggregated results necessary to support the findings are reported in the manuscript and supplementary materials. To facilitate methodological reproducibility, the analytical code and associated documentation are provided as Supplementary Code S1. The code package does not include example datasets; users may apply the documented workflow to independently obtained datasets. Reproduction of the exact study-specific numerical results, however, requires access to the restricted source data.
